00 the entry point in the kit

The method starts before the spec.

Most spec-driven work assumes the shape is known. Uscha treats that assumption as the bug. The expensive failure is a confident build of the wrong shape, so the pipeline runs Discovery first — idea plus references in, a proposed shape out, human decides — and only then specifies.

pipeline.flow
# the order is the contract — do not skip stagesflow = idea → discovery → ready → spec → adr? → build            → verify → evidence → human_gate  # halts here
01 discovery.skill in the kit

The interview compiles clarity, not code.

Two entry skills produce artifacts only: /discovery (idea → shape) and /adr-refine (known shape → sharp edges). Both run with a read/write/search toolset and touch no code.

discovery.skill
allowed_tools: [Read, Write, Glob, Grep]   # +WebFetch for discoveryinvariant: "grill, don't agree"# a discovery where the assistant agreed with everything FAILED.# value = the questions: contradictions, fuzzy terms,#         missing failure modes, unspoken constraints.emit: none until converged_on_shape
An agreeable interviewer inherits your blind spots and returns them formatted as a plan. Friction is the product.
02 package/

Truth is serialized to the repo, not held in chat.

As decisions settle they're written straight to disk. The build reads files; the chat is volatile and dies on the next /clear, compaction, or new session.

CONTEXT.mdDomain glossary — resolves fuzzy language.
DOMAIN-MODEL.mdApproved entities + relations (the shape).
SPEC.mdBehavior, I/O, errors, acceptance, rollback.
docs/adr/*.mdOne per durable decision; executable.
ACCEPTANCE.mdDoD as - [ ]; the readiness input.
RISKS · HANDOFFResidual risk; read-before-coding rules.
Sub-agents read files. CI builds from files. A teammate next week has files, not your transcript. The truth lives in versioned files.
03 spec_vs_adr.rs

Two document types, sorted by what they answer.

classify.fn
fn classify(fact) {  if describes_observable_behavior(fact) => SPEC  if justifies_choice_between(fact)     => ADR}// write an ADR only if ALL three hold:let write_adr = hard_to_reverse             && surprising_without_context             && real_tradeoff;   // else it's noise

The Implementation Plan makes an ADR executable — the agent reads it and builds without re-asking. Code links back with // ADR: <slug>, which makes a later supersede safe.

04 constitution.lock in the kit

Invariants no decision may override.

An ADR chooses; the CONSTITUTION forbids. It's the hierarchy of truth: SPEC says what must happen, ADR says why this shape, CONSTITUTION says what's never acceptable.

CONSTITUTION.md
# non-negotiable — CWE-mapped since v1.1.0secrets_in_logs      = forbidden   # CWE-532/798sql_concatenation    = forbidden   # CWE-89cae_idempotency      = requiredmerge_without_human  = forbidden
⛔ BLOCKERAn ADR may pick MSSQL vs Redis. It may not pick "cert in plaintext" — the constitution vetoes it before alternatives are discussed. A violation caps readiness ≤65 and blocks convergence by construction.

06 dev_loop.orchestrator in the kit

A loop engineered to converge, not to chase zero.

Takes the ADR set + ACCEPTANCE.md, builds, and runs a severity-gated review cycle that stops at the merge gate.

dev_loop.orchestrator
# three laws"converge, don't chase zero""tests are a guardrail, not the finale""generating tests != running tests"phases = [plan, coverage_gate, build, qa_loop,          integration, verify, PR_then_STOP, smoke, docs]while !converged: run(qa_tools); apply(fixes >= gate)  if fingerprint(N) == fingerprint(N-2): oscillation()
⚠ RALPH_WIGGUMSilent failure: the agent emits the "done" token too early. Only an objective gate closes it — never an opinion.
07 evidence.assert

The ledger parses files. It never trusts the narrator.

If the maker writes its own report card, it can log success having run nothing. So qa_ledger.py (pure stdlib) reads the real artifacts instead of the agent's claims.

qa_ledger.py
coverage = parse("jacoco.xml")tests    = parse("surefire-reports/TEST-*.xml")static   = parse(checkstyle, pmd, spotbugs, findsecbugs)assert report.exists else NO_EVIDENCE  # never "OK"
✓ maker ≠ checkerThe one who makes doesn't graduate the work; a checker in fresh context validates it. Anthropic's evaluator-optimizer, Dec 2024. Absent = no evidence.
08 gates.policy

Facts may block; guesses may only advise.

A gate over a fact can stop the work; a gate that guesses over prose can only advise. Break this and false positives kill the gate — the dev disables it and you're worse off.

gatereadseffect
golden-diffbytes vs .approvedBLOCKS
pit-checkmutation XMLBLOCKS
static_gate4 linters, normalizedBLOCKS
spec-checkprose heuristicADVISES
One uncorrelated checker caught 93.4% of what four caught (Osmani). Stack different opinions, not similar linters. Fact gates run in CI, not in the dev's face.
09 golden.anchor new

The one artifact the agent cannot author.

Everything else is agent-authored. A golden captures what the old code actually does by running it, freezes it as human-approved .approved, and diffs the migration against it byte-for-byte.

golden.anchor · hooks
# capture by EXECUTION, never by reasoningreceived = run(old_code, real_corpus)normalize(locale="es-AR", clock, guids, map_order)on PreToolUse(write, "*.approved.*"): DENYgitattributes += "*.approved.* binary"  # or line endings lie
⛔ SACREDIf the agent authored the golden, it'd encode the same partial understanding that lost the logic — and pass against its own mistake. It's a check on the agent, not one it grants itself.
10 outer_loop.proposal proposal

Autonomy compiles only when four conditions pass.

outer_loop.guard
let may_automate = task_repeats_weekly    && automated_verification_exists    && budget_absorbs_waste    && agent_has_senior_tools;  # logs, repro env# heartbeat wraps the inner loop; human still owns merge/loop 0 3 * * *  |  /goal readiness>=80 & 0 CRITICAL  stop = goal_met(fresh_checker) || budget_out
⚠ SECURITY_TAXUnattended loop = unattended attack surface. SAST + secret-scan + dep-audit before any PR; vet every skill (520/17,022 leaked creds); non-verbose logs; re-audit perms every 30d, start read-only; rotate the session before it bloats.
Fiscal/e-invoicing, payments, critical retail sit on the "do NOT autonomize" side. Gated-by-design is the decision, not a gap. Metric once automated: cost per accepted change — below 50% accept, the loop is losing.

13 reproduce.bootstrap

Behavior is seven layers, not one file.

Cloning to a teammate means config, plugins, skills, agents+commands, hooks, the external CLI, and MCP servers — copying settings.json alone isn't enough.

⛔ GOTCHAsettings.json hardcodes C:\Users\…. The bootstrap tokenizes the path on export and rewrites it to the local user on import.
✓ earned, not copiedMemory is not shared: engram + MEMORY.md are per-machine and build themselves as you work. Behavior is replicated; memory is earned.
