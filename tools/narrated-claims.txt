# Retired narrated claims (kit 1.98.0, smoke T154, AC-VC-01/02).
#
# A "VISION" / "planned" / "not yet" label is a promise the reader cannot check. The 1.98.0 rule
# is that such a label either gets WIRED (built and measured) or gets REWRITTEN as the honest
# state -- rejected, deferred by a dated decision, or by design. This file is the ledger of the
# ones that were rewritten, and the smoke suite asserts they stay rewritten: a phrase listed here
# MUST NOT appear in the path listed beside it.
#
# This is an ALLOWLIST, deliberately -- not a general ban on the word VISION. ONE label is
# correct today and must survive: the diamond table's "arbitrary systems" row (still VISION: the
# bounded half is measured, generalization is not). Until 1.99.0 there was a second --
# "cross-vendor is not yet measured" -- and entry 7 below is what happened to it: ADR-042
# measured it, so the label was retired by being ANSWERED rather than by being rewritten, which
# is the outcome this whole doctrine is supposed to produce. A blanket scan would flag the
# survivor, and a gate that flags what is right trains the reader to ignore it. It also means the historical record --
# `uscha-kit/CHANGELOG-*.md`, `audits/`, the paper's "Future Work", ISSUES-DEFERRED.md as a
# mechanism name, and every code/CSS token -- is out of scope by construction: nothing scans
# them, because nothing but the paths below is scanned.
#
# Adding a row is how a release retires a claim. Removing one is how a release un-retires it,
# and that needs a reason in the changelog.
#
# Syntax. Blank lines and `#` comments ignored. One directive or entry per line.
#   base = <git ref>      the commit the twin comparison in [twins] is measured against
#   [retired]             entries are `path :: phrase-that-must-be-absent`
#   [twins]               entries are `pathA :: pathB`, an ES/EN twin pair
# Paths are repo-relative with forward slashes and must exist (a row pointing at a deleted file
# would pass by accident, which is the failure mode this whole file exists to refuse).

# Repo rule 3: the twins travel together. For each pair the two files are diffed against `base`
# and the changed-line counts must be EQUAL -- an edit that landed in one language and not the
# other is exactly the drift this rule exists to catch, and it is otherwise invisible until a
# reader who only speaks the other language finds it.
#
# Say what this measures, because the criterion is a PROXY and reading it as more would be its own
# narrated claim: it compares changed-line COUNTS, not meaning. Equal counts cannot prove the two
# edits say the same thing, and unequal counts do not prove one is wrong -- they prove the twins
# moved differently, which is the cheap mechanical signal worth having. A deliberately asymmetric
# edit is legitimate; whoever makes one bumps `base =` above to the release that carries it, and
# says so in that release's changelog. That bump is the human judgment the count cannot supply.
#
# This file is NEVER added to tools/facts-gated-files.txt. It exists to hold the exact strings the
# claims gate must never see again; a writer pointed at it would rewrite the evidence.
