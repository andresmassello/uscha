# Code of Conduct

## The short version

Be decent. Argue with the work, not the person. Assume the other side is trying to build
something good and may simply have different information.

## Expected

- Technical criticism is welcome and wanted — this project was improved several times by
  reviewers who found real defects in it. Bring evidence.
- Disagree with a claim by showing what it does not do.
- Accept a correction the same way you would like yours accepted.

## Not accepted

Harassment, personal attacks, demeaning comments, unwelcome attention, publishing someone's
private information, or persistent disruption after being asked to stop.

## Scope

Issues, pull requests, discussions, commit messages, and any space where you are representing
this project.

## Enforcement

Report to the address on the author's GitHub profile. Reports are handled privately. The
maintainer may edit, hide or remove contributions, and may block accounts, when this is not
followed.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
shortened deliberately: a code of conduct nobody reads protects nobody.
